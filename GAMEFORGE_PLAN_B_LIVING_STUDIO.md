# GameForge AI — Current Product Structure

GameForge is organized around independent projects and a simple production path.

## Project data

Each project stores its own brief, Story, Characters, World, Quests, Dialogue, AI Producer review, production information, handoff state, and generated GDD. The browser migrates an older single active project into the new project library automatically.

## Design completion

Design readiness is measured across six core sections only. GDD is not counted as a design task because it is the final compiled output.

## Final documentation

The Final GDD page assembles saved project content automatically. A completed project can persist its generated GDD, while an incomplete project can still preview and export a clearly marked draft. Changing core project content clears the older generated GDD so it can be rebuilt from current data.

## Removed active concepts

Living Bible, Scenario Lab, duplicate recommendation panels, repeated progress widgets, and multiple export entry points are no longer part of the active navigation or primary workflow.
